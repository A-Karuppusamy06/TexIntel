# Textile Aura Predict

Textile Aura Predict is a modern web application that provides AI-powered textile market predictions, trend analysis, and industry news through an interactive dashboard. The application offers real-time insights with a clean and responsive user interface.

## Features

- 📊 Interactive Dashboard
- 🤖 AI-based Textile Price Predictions
- 📈 Market Trend Analysis
- 📰 Latest Textile Industry News
- 👤 User Authentication
- 🔐 Admin Panel
- 🌙 Light & Dark Theme Support
- 📱 Fully Responsive Design

## Installation

### Clone the repository

```bash
git clone https://github.com/A-Karuppusamy06/TexIntel
```

### Navigate to the project

```bash
cd textile-aura-predict
```

### Install dependencies

Using npm

```bash
npm install
```

or using Bun

```bash
bun install
```

### Run the development server

Using npm

```bash
npm run dev
```

or

```bash
bun dev
```

The application will start on:

```
http://localhost:5173
```

## Build for Production

```bash
npm run build
```

or

```bash
bun run build
```
